## What This App Is

A browser-based task management app for Parthiban to assign and track tasks for his direct reports, with a dedicated 1:1 view per team member. It runs as a local HTML file — no hosting, no servers, no cost.

---

## 1. Google Sheets Requirements

You need **one sheet per team member** plus one central config sheet. All sheets live in your Google Drive.

### Individual Task Sheets (one per team member)

- **Naming convention:** `Tasks_[FirstName]` — e.g. `Tasks_Hajreta`, `Tasks_Sofia`, `Tasks_Rohit`, `Tasks_Festus`
- The tab name at the bottom of the sheet **must match exactly** — capital T, capital first letter of name, no spaces
- **Column structure (Row 1 = headers, exact spelling):**

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| TaskID | AssignedTo | Task | DueDate | Priority | Status | Notes |

- TaskID format: `TSK-001`, `TSK-002` (auto-generated by the app)
- DueDate format: `MM/DD/YYYY`
- Priority values: `High` / `Medium` / `Low`
- Status values: `Not Started` / `In Progress` / `Completed`
- **Sharing:** Share each sheet only with that team member + Parthiban (Editor access)

### Adding a New Team Member in the Future

1. Create a new Google Sheet named anything you like
2. Add the tab inside named `Tasks_[FirstName]`
3. Add Row 1 headers: `TaskID | AssignedTo | Task | DueDate | Priority | Status | Notes`
4. Share the sheet with that person and Parthiban
5. Copy the Sheet ID from the URL (see Config Sheet section below)
6. Add a new row to `TeamManager_Config` with their name, PIN, Role = Member, and SheetID

## 3. Apps Script — The Proxy

### What It Does

The app cannot call Google Sheets directly from a browser file due to CORS restrictions. The Apps Script acts as a middleman — the HTML file calls the Apps Script URL, which reads and writes the Google Sheets on behalf of the app.

### Current Deployment

- **Project name:** (your new Apps Script project)
- **Web App URL:** `https://script.google.com/macros/s/AKfycbz7r-TEanf7GsxPr4FG4QUyhg-US8noF8gi4Z6bT4luLQQ3LLRuNbcwXr6CojuLwpm9ug/exec`
- **Execute as:** Me (Parthiban)
- **Access:** Anyone

### What Actions It Supports

| Action | What It Does |
|--------|--------------|
| `getConfig` | Reads all rows from TeamManager_Config |
| `getTasks` | Reads all rows from a member's task sheet |
| `appendRow` | Adds a new task row to a member's sheet |
| `updateRow` | Updates an existing row (edit task) |
| `deleteRow` | Deletes a row (delete task) |

### How to Make Changes to the Apps Script

1. Go to [script.google.com](https://script.google.com)
2. Open your project (TeamManagerProxy or whatever you named it)
3. Make your changes to `Code.gs`
4. Click **Save** (Ctrl+S)
5. Click **Deploy → Manage deployments**
6. Click the ✏️ pencil (edit) on the existing deployment
7. Change **Version** to **"New version"**
8. Click **Deploy**
9. The URL stays the same — no changes needed in the HTML file

> ⚠️ **Important:** Every time you change the Apps Script code, you MUST redeploy as a new version. Otherwise the old cached version keeps running.

### If You Ever Need a New Apps Script URL

If you create a fresh deployment and get a new URL, open `TeamManager_v1.html` in a text editor (Notepad, VS Code, etc.), find the line:

```javascript
const PROXY_URL = "https://script.google.com/macros/s/...";
```

Replace the URL with the new one and save the file.

## 4. Technology Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| Frontend | Plain HTML + CSS + JavaScript | Single file, no install, runs in any browser |
| Data storage | Google Sheets | Free, familiar, no database needed |
| API bridge | Google Apps Script (Web App) | Bypasses CORS, runs as you, free |
| Styling | Inline CSS | No dependencies, fully self-contained |
| Authentication | Name + PIN (validated against Config Sheet) | Simple, no OAuth needed |
| Hosting | None — runs as a local file | Zero cost, zero maintenance |

### No npm, no Node.js, no React, no build step.
The final app is a single `.html` file that any browser can open directly from your desktop or Downloads folder.

## 5. Making Changes in the Future

### Recommended Workflow

1. Open this Claude Project (the one where you built v1)
2. Upload the latest `.html` file
3. Describe what you want changed
4. Claude will make targeted edits and save a new versioned file (v2, v3, etc.)
5. Download the new file and replace the old one on your desktop

### Version Naming Convention

`TeamManager_v1.html`, `TeamManager_v2.html`, etc.  
Keep old versions — they're your rollback if something breaks.

### Types of Changes and What They Touch

| Change | Files to update |
|--------|----------------|
| UI/design change | HTML file only |
| New field in tasks | HTML file + Apps Script (if new sheet column) + add column to all task sheets |
| Add a new team member | Config Sheet + create their task sheet + no code changes needed |
| Remove a team member | Delete their row from Config Sheet |
| Change someone's PIN | Edit their row in Config Sheet directly |
| New feature (e.g. Meeting Notes tab) | HTML file + possibly Apps Script |
| Apps Script logic change | Apps Script only + redeploy as new version |

### Things You Can Change Directly in Google Sheets (No Code Needed)

- Add/remove team members → edit Config Sheet
- Change PINs → edit Config Sheet
- Manually edit any task → edit the task sheet directly
- The app will reflect changes on next load/refresh

### Things That Require Uploading the HTML to Claude

- Any visual or layout change
- New features (goals tab, meeting notes, charts, etc.)
- Adding new task fields
- Changing the filter or sort behavior

## Quick Troubleshooting

| Problem | Likely Cause | Fix |
|---------|-------------|-----|
| Names not loading | Apps Script URL wrong or not deployed | Test the URL directly in browser, redeploy |
| "Failed to fetch" | Apps Script access not set to "Anyone" | Redeploy with access = Anyone |
| Invalid PIN | PIN stored as number not string | Format PIN column as Plain Text in Config Sheet |
| Task not loading for a member | Sheet tab name doesn't match `Tasks_[FirstName]` | Rename the tab exactly |
| "Cannot read appendRow" | Sheet tab name wrong or SheetID wrong | Check Config Sheet row for that member |
| Changes not reflected after script edit | Forgot to redeploy as new version | Deploy → Manage → New version → Deploy |
